## 🎯 What Is CookieFi?

CookieFi is an all-in-one SVM application built to showcase the sub-second finality (350ms) and low deployment costs (~$0.05) of **Cookie Chain**.

### Key Features:
1. **Bonding Curve Token Launchpad**: Deploy new SVM tokens in one transaction for ~$0.05.
2. **Cookieswap Terminal**: Instant token swaps with 0.05% fee and sub-second execution.
3. **CookieScan Explorer**: Live telemetry feed pulling block and TPS metrics via `api.cookiescan.io`.
4. **Cookie-MCP Integration**: Model Context Protocol integration for AI agent interaction with Cookie Chain.
